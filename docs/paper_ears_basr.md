# 按论文修正 EARS 与 BASR

本修改对应《Video Frame Interpolation via Asymmetric Refinement with the Event-based Reference》的第 III-A 节、图 4，以及第 III-C 节的公式 (4)–(8)。保留公开网络的可训练参数名称与形状，修改掩码生成、区域选择及局部修复行为。

## 事件掩码 M

1. 将前后两段、正负极性的事件计数合并为二值发生图。
2. 在 3×3 窗口中，统计与中心值不同的 8 个邻居；数量**超过 δ=6** 时翻转中心。所有判断基于原图同时进行，不是按遍历顺序更新。
3. 使用 5×5 膨胀连接事件区域。

图像边界使用零填充。这是明确选定的边界约定，论文没有单独规定边界行为。`process_mask` 同时支持 `[C,H,W]` 和 `[B,C,H,W]`，卷积核跟随输入设备。

## BASR 区域选择

按照公式 (4)–(6)：

```text
D_i = 1[sum_channels(abs(I_i - I_coarse)) > 0]
D_i_event = D_i * M
H_i = patch_sum(D_i_event) >= beta * patch_size
```

使用不重叠的 p×p patch、步长 p。默认 p=32、β=0.1，所以一个 patch 至少需要 4 个同时满足“图像发生变化、事件掩码有效”的像素。按原文使用严格大于零的二值化，不额外添加 RGB 差异阈值。按公式保留 `>=`，因此 β=0 时所有 patch 都满足阈值。

原来的“RGB 原始误差求和与 β 比较，再看 patch 内是否出现事件”已替换。H0 与 H1 交换后使用：帧 0 提供 H1 的支持，帧 1 提供 H0 的支持。返回的结构损失掩码仍是 H0∪H1。

## 局部注意力与写回

按照公式 (7)，同一方向的 Query 和 Key/Value 都只从所选 patch 中提取，在选中 token 间计算注意力，再把残差放回原位置。未选 Query 的残差为零；没有选中 patch 的样本跳过 softmax。两侧继续共享注意力权重。

融合卷积可能通过偏置、邻域感受野改变选择区外的特征，因此融合后按上采样的 H0∪H1 门控：选择区域采用融合结果，其余位置严格保留全局解码器的 `f_up`。这是对论文“局部修复、其他区域交给原解码器”语义的显式实现；论文没有给出这一步完整代码。整个模块遇到空选择时直接返回 `f_up`。

## 权重与使用

没有新增、删除或改变可训练参数，当前源码对应的旧权重可继续严格加载。保留了原代码未使用的投影参数，以兼容 state_dict。加载旧权重后的前向行为会变化，应在新输出目录中微调或重训并重新评测，不能保证指标一定提升。

训练、测试的调用方式不变，默认仍为 bins=8、mask_patch_size=32、beta=0.1。本次修改只处理 EARS 与 BASR，不包含事件时间归一化或 MaskedSSIMLoss 的修改。

## 验证

在安装项目运行依赖和 pytest 后，从项目根目录执行：

```bash
python -m pytest -q tests/test_paper_masks_basr.py
```

覆盖阈值边界、5×5 膨胀、二值有效像素计数、反向支持路由、空掩码、未选区域保持、混合 batch、梯度以及矩形输入的完整网络前后向。测试不需要训练数据或预训练权重；不代表已完成 BS-ERGB 指标复测。

本次验证结果：CPU 环境下 12 项测试全部通过；另外通过 256×256、448×448 的完整网络前向与有限值检查，并验证修改前网络参数字典可严格加载到修改后网络。未执行 CUDA 训练或 BS-ERGB 指标复测。
